# Легче — приложение

## Установка и сборка

Используем Node.js 22.23.4 и npm 10. Версия Node для nvm указана в `.nvmrc`.
Единственный менеджер пакетов — npm. У фронтенда и API свои `package.json`
и `package-lock.json`; оба lock-файла хранятся в Git.

```bash
npm ci --include=dev
npm run typecheck
npm test
npm run build

cd server
npm ci --omit=dev
```

`npm ci` устанавливает версии из lock-файла. При расхождении с `package.json`
установка останавливается. Не заменять её на `npm install` при развёртывании.
При намеренном изменении зависимостей использовать `npm install` в нужной
папке и включать в коммит оба файла: `package.json` и `package-lock.json`.
После этого проверить чистую установку, типы, тесты и сборку.

`npm run build` и `npm run build:dev` сначала проверяют типы приложения
и конфигурации Vite, затем smoke-тесты навигации и согласованность каталога рецептов. Ошибка любого
этапа останавливает сборку. Текущие конфигурации TypeScript не ослаблены.
Smoke-тесты переходов из поиска в карточки шести разделов и навигации меню:

```bash
npm run test:smoke
```

Docker использует Node.js 22 и `npm ci` для обоих сервисов. Bun и его
lock-файлы больше не используются. Перед обновлением рабочего сервера
проверяем тот же коммит на тестовом окружении; сохраняем предыдущие образы.
Теги базовых Docker-образов могут обновляться: lock-файлы фиксируют версии
npm-пакетов, но не гарантируют побайтовую неизменность всей ОС образа.
